description=[h2]FAQ[/h2]
description=
description=[b]Does this mod work in multiplayer (build 42.13+)?[/b]
description=[list]
description=  [*]Yes, the mod has been updated with initial multiplayer support. Servers will use the default mod options (1.0 rain factor, pipe wrench required) until configurable sandbox values are added in a future update.
description=[/list]
description=
description=[b]Can this mod be safely added mid-save?[/b]
description=[list]
description=  [*]Yes, but it will not change any already existing collectors that happen to be placed on a gutter tile.
description=[/list]
description=
description=[b]Can this mod be safely removed mid-save?[/b]
description=[list]
description=  [*]Yes, but extra steps are required for multiplayer. See the removal section below.
description=[/list]
description=
description=[b]Do gutter collectors work indoors?[/b]
description=[list]
description=  [*]No, currently they still require being outdoors without a covered overhead tile.
description=[/list]
description=
description=[b]What can I connect to the gutter[/b]
description=[list]
description=  [*]All vanilla rain collectors, troughs, and the amphora are supported. Additionally, any modded entities that use the game's FluidContainer system should work out of the box such as the Useful Barrels mod.
description=[/list]
description=
description=[b]Does this work for build 41?[/b]
description=[list]
description=  [*]This mod relies on systems introduced in build `42.4+` and will not function in build `41`.
description=[/list]
description=
description=[h2]How To Use[/h2]
description=[olist]
description=  [*]Build/place supported collector on the same tile as a gutter drain. Either tile works for multi-tile troughs.
description=  [*]Open the context menu by right-clicking on the collector.
description=  [*]Find the [b]"Gutter Drain"[/b] submenu and select the [b]"Connect"[/b] option. Requires a pipe wrench unless turned off in mod settings.
description=  [*]Enjoy the benefits of a highly-efficient rain collector system.
description=[/olist]
description=
description=[h3]Pre-Existing Structures[/h3]
description=Pre-existing structures already have roof gutters meaning you won't have to build your own. To tap into these roof gutters, you will either need to find a building with an existing drain pipe or build a new drain pipe.
description=
description=On its own a drain pipe will reach the next level above. Additional vertical pipes can be built on top of the drain pipe to access roofs on higher floor levels.
description=
description=[h3]Player-Built Structures[/h3]
description=Unlike pre-existing structures, player-built structures will require horizontal gutter pipes to expand the size of the roof's area being covered by the drain pipe. Each gutter pipe can collect rain from up to 4 grid-squares from its attachment point in a line. A roof square will be considered valid if it has a floor, isn't covered by a roof, and isn't occupied by an item such as a rain collector.
description=
description=Use the "View Pipes" and "View Roof" buttons in the gutter ui panel to help visualize the connected pipes and covered roof area.
description=

description=[h2]Removing Mod from Multiplayer[/h2]
description=As of 42.13.1, there is an extra step required to properly remove the mod from multiplayer servers. This process is not specific Functional Gutters and will be required for any mods that add custom entities until a fix is added in the base game.
description=
description=[h3]Removal Methods[/h3]
description=Choose one of the following methods to maintain an active multiplayer save:
description=
description=[b]Placeholder Mod[/b]
description=To help facilitate removal, a second mod titled "[42] Functional Gutters (Removed)" has been included alongside the main mod. This placeholder mod maintains all entity scripts and tile definitions but none of the main mod's core functionality.
description=[olist]
description=  [*]Stop the server
description=  [*]Backup the server files if not done automatically on server shutdown
description=  [*]Disable the main mod "[42] Functional Gutters" in the server settings
description=  [*]Enable the placeholder mod "[42] Functional Gutters (Removed)" in the server settings
description=  [*]Start the server back up
description=[/olist]
description=
description=[b]Manual[/b]
description=[olist]
description=  [*]Remove any player-crafted gutters from the game world - not required but will prevent invisible asset warnings being logged
description=  [*]Stop the server
description=  [*]Backup the server files if not done automatically on server shutdown
description=  [*]Remove the mod from the server settings
description=  [*]Locate and delete the following server files: WorldDictionary.bin, WorldDictionaryLog, WorldDictionaryReadable - location may differ but for hosted files on windows will be Users/<user name>/Zomboid/Saves/Multiplayer/<server name>
description=  [*]Start the server back up - this will automatically regenerate the WorldDictionary files and allow clients to connect without crashing
description=[/olist]
description=
description=[h3]But why do I need to do all of this?[/h3]
description=The client syncs its own local copy of the server's WorldDictionary when connecting to the server. Any custom entities will still exist in the server's WorldDictionary with the flag removed=True whenever a mod is removed. Unfortunately in the current version of project zomboid multiplayer, this flag appears to be ignored and the client will crash with a reference error since the referenced entity scripts no longer exist for it locally.
description=
description=Deleting the server's WorldDictionary files forces the server to recreate them from scratch and they will no longer contain any entities from the removed mod allowing the client to properly connect once again.
description=
